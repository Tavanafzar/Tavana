### توانا چیست؟

**توانا (Tavana)** یک دستیار هوشمند، سریع و سبک برای **Windows 10 و Windows 11** است.

توانا یک رابط ساده و یکپارچه برای دسترسی سریع به فرمان‌های ویندوز، برنامه‌ها، بازی‌ها، ابزارهای سیستمی، محاسبات ریاضی و جست‌وجوی اینترنتی فراهم می‌کند.

به‌جای اینکه کاربر در منوهای مختلف ویندوز، Settings، Control Panel یا پوشه‌های مختلف جست‌وجو کند، می‌تواند تنها چیزی را که نیاز دارد در توانا وارد کند.

### 🎯 ایده اصلی توانا

ویندوز ابزارها و تنظیمات بسیار زیادی دارد، اما پیدا کردن بعضی از آن‌ها همیشه ساده نیست.

توانا این مسیر را کوتاه می‌کند. به‌جای اینکه کاربر بپرسد «این گزینه کجاست؟»، می‌تواند مستقیماً چیزی را که نیاز دارد وارد کند. توانا ورودی را بررسی می‌کند، در مجموعه فرمان‌ها جست‌وجو می‌کند و نتیجه مناسب را در اختیار کاربر قرار می‌دهد.

### ⚡ دسترسی سریع

توانا برای این طراحی شده است که تا زمانی که به آن نیاز ندارید، مزاحم کار شما نباشد.

#### نمایش توانا

کلیدهای زیر را فشار دهید:

```
Ctrl + Space
```

پنجره توانا نمایش داده می‌شود و می‌توانید بلافاصله ورودی خود را وارد کنید.

این میانبر برای دسترسی سریع و استفاده مداوم از توانا طراحی شده است.

### 🪟 اجرای فرمان‌های ویندوز

توانا امکان دسترسی سریع به تعداد زیادی از ابزارها و بخش‌های ویندوز را فراهم می‌کند. برای مثال:

```
کنترل پنل
مدیریت وظایف
اتصالات شبکه
مدیریت دستگاه
برنامه‌ها و قابلیت‌ها
Command Prompt
PowerShell
تنظیمات ویندوز
```

نمونه فرمان‌ها:

```
control
ncpa.cpl
appwiz.cpl
cmd
powershell
ms-settings:
```

### 📁 پیدا کردن برنامه‌ها و بازی‌ها

توانا می‌تواند برای پیدا کردن برنامه‌ها و بازی‌های نصب‌شده نیز استفاده شود. به‌جای جست‌وجوی دستی در پوشه‌های مختلف، کافی است نام برنامه یا بازی را وارد کنید.

توانا می‌تواند نتیجه مناسب را پیدا کند و امکان اجرای آن را فراهم کند.

### 🧮 ماشین حساب

توانا امکان محاسبه عبارت‌های ساده ریاضی را نیز فراهم می‌کند. مثلاً:

```
25 * 18
(120 + 80) / 4
1250 / 5
15 ** 2
```

بنابراین برای محاسبات سریع، نیازی به باز کردن برنامه دیگری ندارید.

### 🔎 جست‌وجوی Google

اگر عبارت واردشده یک فرمان شناخته‌شده یا برنامه محلی نباشد، می‌توان از آن برای جست‌وجوی Google استفاده کرد. مثلاً:

```
چگونه پایتون را روی ویندوز نصب کنیم
```

یا:

```
Windows 11 shortcuts
```

توانا عبارت را برای جست‌وجو آماده می‌کند.

### 🌐 پشتیبانی از فارسی و انگلیسی

توانا با هدف پشتیبانی از کاربران فارسی‌زبان و انگلیسی‌زبان طراحی شده است. نمونه ورودی‌های فارسی:

```
بلوتوث
وای فای
کنترل پنل
مدیریت دستگاه
تنظیمات شبکه
```

### 🎨 رابط کاربری

رابط کاربری توانا از ایده **Command Palette** الهام گرفته است. فرآیند کار بسیار ساده است:

```
نمایش توانا
     ↓
وارد کردن درخواست
     ↓
تشخیص ورودی
     ↓
جست‌وجو
     ↓
نمایش نتیجه
     ↓
اجرای عملیات
```

> **کاهش مسیر دسترسی به قابلیت‌های ویندوز.**

### 🔐 حریم خصوصی

توانا برای اطلاعات اصلی فرمان‌ها می‌تواند از یک دیتابیس محلی **SQLite** استفاده کند. اطلاعاتی مانند:

```
نام فرمان
فرمان ویندوز
دسته‌بندی
توضیحات
آیکون
کلیدواژه‌ها
```

می‌توانند به‌صورت محلی ذخیره شوند.

برای استفاده از قابلیت‌هایی که عمداً به سرویس‌های آنلاین متصل می‌شوند، مانند جست‌وجوی Google، دسترسی اینترنت لازم است.

### 🏗️ معماری

توانا با هدف جداسازی رابط کاربری از منطق اصلی برنامه طراحی شده است.

```
                         Tavana
                            │
              ┌─────────────┴─────────────┐
              │                           │
          رابط کاربری                 Core Engine
              │                           │
              │              ┌────────────┼────────────┐
              │              │            │            │
              │           Search       Commands    Calculator
              │              │            │            │
              └──────────────┴────────────┴────────────┘
                             │
                       Local Database
                           SQLite
```

این ساختار توسعه و نگهداری پروژه را ساده‌تر می‌کند.
